Política de Privacidade

Última revisão: 28 de março de 2024

A Política de Privacidade do site restaurantetempeh.com.br visa informar aos usuários sobre como seus dados pessoais são tratados e protegidos. Este documento é regido principalmente pela Lei Geral de Proteção de Dados Pessoais (LGPD), que estabelece diretrizes para o tratamento adequado das informações pessoais.

  1. Controlador dos Dados Pessoais

  • O restaurantetempeh.com.br é controlado pessoa jurídica responsável pelo tratamento dos dados pessoais coletados.

  1. Dados Coletados e Utilizados

  • Informamos aos usuários quais dados pessoais são coletados e utilizados pelo site. Isso inclui informações como nome, endereço de e-mail, número de telefone, entre outros.

  • Os dados são coletados nos seguintes momentos:

    • Quando o usuário se cadastra no site.

    • Durante a navegação, por meio de cookies e tecnologias similares.

  • Os dados são utilizados para os seguintes fins:

    • Personalização da experiência do usuário.

    • Envio de comunicações relacionadas ao site e serviços.

    • Análise de métricas e melhorias no site.

  1. Direitos dos Usuários

  • Os usuários têm direito a:

    • Acessar seus dados pessoais.

    • Corrigir informações incorretas.

    • Solicitar a exclusão dos dados.

    • Revogar o consentimento para o tratamento.

    • Obter informações sobre o compartilhamento dos dados.

  1. Encarregado de Proteção de Dados Pessoais (DPO)

  • O restaurantetempeh.com.br possui um Encarregado de Proteção de Dados Pessoais responsável por garantir a conformidade com a LGPD. Para entrar em contato com o DPO, utilize os seguintes meios:

    • E-mail: dpo@restaurantetempeh.com.br

  1. Bases Legais para o Tratamento de Dados Pessoais

  • O tratamento dos dados pessoais é fundamentado nas bases legais previstas na LGPD.

  1. Alterações na Política de Privacidade

  • Reservamo-nos o direito de atualizar esta política periodicamente. As alterações serão comunicadas aos usuários por meio do site.

Lembramos que este documento não abrange as normas contidas no Regulamento Geral de Proteção de Dados da União Europeia (RGPD).
